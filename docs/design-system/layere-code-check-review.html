LayerE design system: what the code check changes

Everything below is staged, not published. It fixes what I got wrong, fills the gaps the source answers, explains the shipped deviations and adds your real app icons. Two items reverse earlier decisions, so they need your call first.

!Needs your call

1 · Dialog button order: OK · Cancel · Apply

The Dialog card adopted Appearance's Apply · OK · Cancel. Options uses OK · Cancel · Apply, which is also the standard Windows order, so I staged that instead and listed Appearance as the deviation.
