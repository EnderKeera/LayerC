# MenuBar

A `background` strip with a 1 px `divider` line along its bottom: File, Edit, View, Tools, Help. Items take `button_hover` under the pointer.

- **The menus:** File, Edit, View, Tools, Help, each command in one of them; Menus lists their contents and the context menus. Sentence case throughout.
- **Shortcuts** sit right-aligned in each item (`\t` in the menu resource).
- **Drop-down menus:** the dark system menu on Windows (`install_dark_menu_bar`); outlined flat boxes on Linux, whose bar line is halfway between its outline and fill.
- **Text:** `text`, in the body style.

The consumer supplies the menu titles and their commands.

The preview is a static HTML rendition of these rules; the painters named above are the source of truth. The Screens pages show it in place.
