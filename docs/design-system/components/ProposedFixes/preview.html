With the desktop font at 18 px, the clamp holds the editor at 14 px and the status text at 11 px. Proposed: sizes above 14 px set FLTK’s screen scale, so the fixed layout grows with the text and status text matches the body size.

17Overlay flashing capped at 3 Hz

Now
4 flashes in one second
Proposed
3 flashes in one second

Indicator items allow flashHz up to 4. WCAG 2.3.1 sets the limit at three flashes per second. Profiles keep loading unchanged; every renderer flashes at min(flashHz, 3) through one core helper, and the editor accepts 0.5–3 with a warning on a loaded value above 3.
