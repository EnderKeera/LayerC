# EmptyState

What an empty list shows: centered inside the list, one `secondary` line saying what is missing and one `subtext` line saying how to add it.

- Use the words of the control that adds the thing: "Choose a preset above and press New."
- Never leave a list blank, and never put the explanation beside the list instead of in it.

The consumer supplies the two lines.

The preview is a static HTML rendition of these rules.
