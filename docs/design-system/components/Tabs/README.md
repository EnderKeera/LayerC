# Tabs

Linux tabs: flat squares in a row. The selected tab carries the `selection` tint and a 3 px `accent` bar along its top (`accent-rail`); unselected tabs use `panel`.

- The bar is the signal: the tint alone is at most 1.3:1 against an unselected tab, the bar 4.7:1 or more against `panel` in every preset.
- A focused tab takes the 2 px `accent` ring.
- Outlines follow `control_border` (`linux-outline-panel` on a `panel` tab).
- The main window's tabs run from Profile to Visual (270, 15, 775 × 435).
- Text in `linux-body`.

Windows has no tabbed surface in this system. The consumer supplies the tab labels and the selected tab.

The preview is a static HTML rendition of these rules; the painters named above are the source of truth.
