# Screenshots

Screenshots of the shipped Windows editor at 96 DPI in Graphite / Copper, one pixel per logical pixel. They are the reference the Screens pages are measured from: use them to check a rendition, never as UI images.

- `main-window.png` — the main window with the profile "iwcs" open (1195 × 754).
- `automation.png` — Automation before the first automation exists (993 × 696).
- `keyboard-shortcuts.png` — Help's keyboard shortcut list (330 × 312).
- `appearance-choose-color.png` — Tools > Appearance with Choose color open on top (874 × 598).
