# Logos

LayerC's app icons, copied from the repository (`resources/windows/*.ico`, largest frame, and the 16 px frame). Use the files as they are; never redraw or recolor the mark.

- `layerc-editor.png` — LayerE, the editor: the cooldown ring with a #50bac8 pencil. The Linux editor ships the same picture (`packaging/linux/icons`, 48–256 px).
- `layerc.png` — LayerC and LayerD: the bare ring.
- `layerc-calibration.png` — layercal: the ring with a crosshair.
- `layerc-16.png` — every icon at 16 px, where the badge drops away: the title bar of each window.

The ring is `preset-copper` (#d88e4b) over a #3e444e track on a #1e232a rounded square. On the dark `background` the icon needs no plate or outline.
