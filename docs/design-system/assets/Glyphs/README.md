# Glyphs

The four status glyphs, drawn on a 12 px grid with 2 px square strokes, shown here at 4×. Paint them at 12 px in their token's color: `yes.svg` in `yes`, `no.svg` in `no`, `warning.svg` in `warning`, `accent_2.svg` in `accent_2` (blue here; violet on Teal and Slate). Each SVG has its ink baked in, since an image can't take the text color. Always put the status word beside the glyph.
